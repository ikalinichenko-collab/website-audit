## How we vet: GoGloby Talent Assessment Model

Every engineer GoGloby places passes a 4-stage technical assessment for production AI work, plus a culture-fit interview, reference checks and a full background check. Approximately 4% of candidates pass.

| Stage | Question | Task |
| :---- | :---- | :---- |
| 1 | Can they specify? | Write a structured specification from a loose business requirement. No code. |
| 2 | Can they navigate? | Refactor a real 50,000-line codebase with an AI coding tool. Observed. |
| 3 | Can they architect? | Design a multi-agent system. |
| 4 | Can they govern? | Run the first 60 minutes of a production hallucination incident. |
